# 真机试用清单

应用：弦准 0.2.0（暂用名）。可直接发送签名 APK 到手机覆盖安装，或通过 USB 安装。

## 连接手机

1. 在手机“关于手机”中多次点击版本号，启用开发者选项（不同品牌入口可能不同）。
2. 开启 USB 调试，用支持数据的 USB 线连接 Mac，解锁手机并允许此电脑调试。
3. 某些品牌需要额外开启“通过 USB 安装”；若安装被手机阻止，按手机提示完成授权。
4. 在项目目录运行 `./scripts/install-phone.sh`。首次运行应用时，点击“开始调音”再授予麦克风权限。

## 第一轮测试

记录手机型号、Android 版本、吉他类型、手机与吉他的距离和环境噪声。

- [ ] 首次打开不会自行申请或占用麦克风。
- [ ] 点击开始后授权，拨弦时出现频率和偏差。
- [ ] 自动模式分别识别六根弦，两个 E 弦的弦号/八度正确。
- [ ] 七弦 Drop A 自动识别第七弦 A1（55 Hz），不误认第五弦 A2（110 Hz）。
- [ ] 手动选择第七弦显示目标 55.00 Hz；切回六弦后不残留第七弦目标。
- [ ] 聆听中切换定弦，旧读数清除，继续采音且可暂停。
- [ ] 手动选择六弦后，拨五弦不会自动换成五弦。
- [ ] 用独立参考检查偏高/偏低方向是否正确。
- [ ] 调准后稳定显示“音准刚刚好”；停止拨弦后不保留绿色状态。
- [ ] 轻拨、重拨、重复拨弦、较长余音均无明显八度跳变。
- [ ] 连续使用 30 分钟，观察崩溃、卡顿、发热和耗电。
- [ ] 暂停、锁屏和切换后台时，系统麦克风使用提示消失。
- [ ] 返回前台后，只有此前在调音时才恢复采音。
- [ ] 拒绝权限、撤回权限或关闭系统麦克风时，应用不崩溃并可恢复。
- [ ] 开飞行模式后仍能调音。
- [ ] 耳机插拔、来电或其他应用占用麦克风后，可以重新开始调音。
- [ ] 大字体、横屏和较小屏幕下，开始/暂停按钮仍能使用，内容可以滚动。
